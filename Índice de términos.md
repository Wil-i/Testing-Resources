# Índice de términos

Términos usados en las áreas de la wiki. Cada término indica dónde se usa; al incorporar un área nueva se agregan términos nuevos o se amplía "Usado en" de los existentes.

Cuando el término existe en el glosario ISTQB, su definición es la oficial y literal, con enlace a su entrada en [[Referencias/Glosario ISTQB 4.8.1]], la referencia completa. Los términos que no están en ese glosario conservan su definición anterior: "glosario ISTQB MAT 2019" o, si es redacción propia a partir del capítulo, la marca "Definición derivada del capítulo N".

### Ciclo de vida del software
*Inglés: software lifecycle.* Período de tiempo que comienza cuando se concibe un producto software y finaliza cuando el software deja de estar disponible para su uso. El ciclo de vida del software suele incluir una fase de concepto, una fase de requisitos, una fase de diseño, una fase de implementación, una fase de prueba, una fase de instalación y comprobación, una fase de operación y mantenimiento y, a veces, una fase de retirada. Es preciso tener en cuenta que estas fases pueden solaparse o realizarse de forma iterativa. Fuente: [[Referencias/Glosario ISTQB 4.8.1#ciclo de vida del software|Glosario ISTQB 4.8.1]].
